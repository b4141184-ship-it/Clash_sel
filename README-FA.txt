# Clash_sel — پل سفارش سایت به ربات روبیکا

این پوشه یک نمونه اولیه سرور Flask است. فایل `server.py` سفارش و رسید را می‌گیرد و اطلاعات را به ربات روبیکا می‌فرستد.

## قبل از استفاده
- توکن ربات را در HTML یا GitHub قرار نده.
- سایت استاتیک GitHub Pages به تنهایی نمی‌تواند سفارش‌ها را به ربات بفرستد؛ باید این سرور را جداگانه میزبانی کنی.
- سرویس‌های رایگان ممکن است بخوابند، محدودیت داشته باشند یا فایل‌ها را بعد از راه‌اندازی مجدد پاک کنند.
- برای استفاده واقعی باید قیمت محصولات در سمت سرور اعتبارسنجی شود و ضداسپم/حفاظت بیشتری اضافه شود.
- فقط رسیدهای لازم را جمع‌آوری کن، به خریدار اطلاع بده و فایل‌ها را پس از مدت مشخص حذف کن.

## فایل‌ها
- `server.py`: سرور دریافت سفارش، آپلود رسید و ارسال به ربات
- `requirements.txt`: وابستگی‌ها
- `render.yaml`: تنظیمات اولیه برای سرویس میزبانی Render
- `frontend-integration.js`: نمونه کدی که باید به سایت اضافه شود

## استقرار کلی
1. فایل‌های این پوشه را به یک مخزن GitHub جداگانه آپلود کن.
2. در سرویس میزبانی Python، مخزن را به عنوان Web Service وصل کن.
3. Build command: `pip install -r requirements.txt`
4. Start command: `gunicorn server:app --workers 1 --threads 4 --timeout 120`
5. در بخش Environment Variables، مقدار `BOT_TOKEN` را با توکن واقعی و `ADMIN_CHAT_ID` را با شناسه چت خودت تنظیم کن. توکن را در چت یا فایل‌های عمومی قرار نده.
6. بعد از deploy، آدرس سرویس را در `API_BASE_URL` داخل `frontend-integration.js` قرار بده.

## پیدا کردن ADMIN_CHAT_ID
پس از تنظیم `BOT_TOKEN` و اجرای سرور، در روبیکا به ربات پیام `/start` بده. ربات شناسه چت را پاسخ می‌دهد. همان مقدار را در متغیر امن `ADMIN_CHAT_ID` قرار بده و سرویس را دوباره deploy/restart کن. اگر ربات هنوز در پنل روبیکا فعال نشده یا توکن معتبر نیست، ارسال کار نمی‌کند.

## مهم درباره اتصال فرانت‌اند
فایل `frontend-integration.js` نمونه است و باید با HTML موجود ادغام شود. آن را بدون تنظیم `API_BASE_URL` و بدون افزودن ورودی رسید به فرم، آماده استفاده ندان.
