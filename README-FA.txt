راهنمای Clash_Sel

امکانات: فروشگاه محصولات، پنل افزودن/حذف محصول، ثبت سفارش همراه رسید، مشاهده سفارش‌ها و تغییر وضعیت، پیگیری با کد سفارش و شماره موبایل.

راه‌اندازی:
1) کل پوشه را روی میزبان پایتون قرار بده.
2) دستور نصب: pip install -r requirements.txt
3) متغیرهای محیطی ADMIN_USERNAME و ADMIN_PASSWORD و SECRET_KEY را تنظیم کن.
4) اجرا: python app.py
5) ورود مدیر: /admin/login

رمز پیش‌فرض اولیه CHANGE-ME-NOW است؛ قبل از انتشار حتماً عوضش کن.
GitHub Pages فقط سایت ثابت را اجرا می‌کند و برای این برنامه پایتون مناسب نیست.
Render رایگان ممکن است بخوابد و فایل‌هایش دائمی نیستند؛ برای سفارش‌ها و تصاویر رسید از دیسک پایدار/پایگاه داده مناسب استفاده کن.
ورود پیامکی هنوز به پنل و API شرکت پیامکی نیاز دارد و در این نسخه فعال نیست.
ارسال روبیکا فقط پس از تنظیم RUBIKA_WEBHOOK با وب‌هوک/واسط معتبر فعال می‌شود. توکن را در فایل عمومی یا چت قرار نده.
نسخه اولیه برای آزمایش است؛ لینک رسیدها عمومی است و قبل از فروش واقعی باید ذخیره‌سازی خصوصی و بررسی امنیتی اضافه شود.
